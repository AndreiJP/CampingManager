# CampingManager.Web

Frontend pubblico Angular del campeggio.

## Comandi

```bash
npm install
npm run build
npm start
```

## Struttura

- `src/app/features/home/pages`: pagine pubbliche.
- `src/app/features/home/sections`: sezioni componibili e sostituibili.
- `src/app/shared`: moduli condivisi per direttive Angular, form e routing.
